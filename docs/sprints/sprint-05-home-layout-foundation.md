# Sprint 05 — Home Layout (Foundation)

Version : 1.0

Projet : Aziz Studio Digital V2

Type : Page Foundation

Priorité : Très Haute

Dépendances :

- Sprint 01 — Foundation ✅
- Sprint 02 — Header System ✅
- Sprint 03 — Footer System ✅
- Sprint 04 — UI Components System ✅

---

# Objectif

Construire l'architecture de la page d'accueil.

Aucun contenu définitif ne doit être intégré.

Aucun design spécifique ne doit être développé.

Le but est uniquement de créer la structure HTML de la Home en utilisant les composants du Design System.

---

# Objectif Business

La page d'accueil doit guider progressivement un visiteur vers une demande de devis.

Chaque section devra répondre à une question du prospect.

---

# User Story

En tant que visiteur,

je veux comprendre rapidement :

- qui est Aziz Studio Digital ;
- quels services sont proposés ;
- pour quels secteurs d'activité ;
- pourquoi faire confiance à l'entreprise ;
- comment prendre contact.

---

# Architecture

Créer uniquement :

pages/home.html

---

# Structure attendue

La page devra contenir les sections suivantes dans cet ordre :

1. Hero

2. Secteurs d'activité

3. Services

4. Pourquoi Aziz Studio Digital

5. Réalisations

6. Processus de travail

7. Technologies

8. Témoignages

9. FAQ

10. Derniers articles

11. Appel à l'action final

Chaque section devra utiliser :

- section
- container

issus du Design System.

---

# Contenu

Utiliser uniquement des titres temporaires.

Exemple :

<section id="hero">

<h2>Hero</h2>

</section>

Aucun texte marketing définitif.

Aucune image.

Aucune icône.

---

# Navigation

Chaque section devra posséder un id unique.

Exemple :

hero

services

portfolio

faq

etc.

Ces identifiants serviront aux ancres du Header.

---

# Responsive

La structure doit fonctionner :

- Mobile

- Tablet

- Desktop

---

# Accessibilité

Utiliser :

main

section

header

footer

Titres hiérarchisés.

---

# SEO

Prévoir une structure HTML parfaitement sémantique.

Un seul H1.

Les autres titres devront respecter la hiérarchie.

---

# Performance

Aucun JavaScript.

Aucun style spécifique.

Uniquement la structure HTML.

---

# Contraintes

Ne pas développer :

- Hero

- Services

- Portfolio

- FAQ

- CTA

Créer uniquement leur structure.

---

# Livrables

Créer uniquement :

pages/home.html

---

# Critères d'acceptation

Le Sprint est terminé lorsque :

✔ Toutes les sections existent.

✔ Les IDs sont présents.

✔ La structure HTML est valide.

✔ Les composants du Design System sont utilisés.

✔ Aucune logique métier.

✔ Aucun contenu définitif.

---

# Résultat attendu

À la fin de ce Sprint, Aziz Studio Digital V2 possède le squelette complet de la page d'accueil, prêt à recevoir le contenu de chaque section lors des sprints suivants.

# Sprint 01 — Checklist

Version : 1.0

Projet : Aziz Studio Digital V2

Sprint concerné :

Sprint 01 — Foundation

---

# Objectif

Valider définitivement le Sprint 01 avant de passer au Sprint 02.

Cette checklist constitue le dernier contrôle.

Aucune nouvelle fonctionnalité ne doit être développée.

Aucune modification de l'architecture n'est autorisée.

---

# Checklist

## 1. Architecture

- [ ] La structure des dossiers est respectée.
- [ ] Aucun nouveau dossier n'a été ajouté.
- [ ] Aucun dossier existant n'a été modifié.
- [ ] Tous les fichiers ont été créés au bon emplacement.

---

## 2. Variables CSS

Fichier :

assets/css/base/variables.css

Vérifier :

- [ ] Les variables de couleurs sont présentes.
- [ ] Les variables de typographie sont présentes.
- [ ] Les variables de poids de police sont présentes.

- [ ] Les variables de border-radius sont présentes.
- [ ] Les variables d'ombres sont présentes.
- [ ] Les variables de z-index sont présentes.
- [ ] Les variables de transition sont présentes.
- [ ] Les variables de breakpoints sont présentes.

Fichier :

assets/css/base/reset.css

Vérifier :

- [ ] box-sizing est correctement appliqué.

## 6. Qualité

- [ ] Le code est lisible.

## 7. Responsive

- [ ] Mobile Ready
- [ ] Tablet Ready

## 9. Performance

- [ ] Aucun code inutile.

# Validation finale

Le Sprint 01 est considéré comme terminé uniquement si :

- [ ] Toutes les cases ci-dessus sont validées.
- [ ] Aucun problème critique n'a été détecté.
- [ ] Le Sprint 01 Review a été approuvé.

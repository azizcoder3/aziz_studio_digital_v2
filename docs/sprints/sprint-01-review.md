# Vérifications attendues

## 1. variables.css

Vérifier que toutes les variables sont correctement organisées.

Les catégories doivent être clairement séparées.

- Couleurs
- Typographie
- Font Weight
- Espacements
- Border Radius
- Ombres
- Z-index
- Transitions
- Breakpoints

Les noms doivent être cohérents.

Les variables inutilisées ou dupliquées doivent être signalées.

Ne rien supprimer automatiquement.

---

## 2. reset.css

Vérifier :

✔ margin

✔ padding

✔ box-sizing

✔ images

✔ videos

✔ listes

✔ boutons

✔ formulaires

✔ liens

Le reset doit rester minimal.

Aucun style graphique ne doit être présent.

# Sprint 01 — Foundation

Version : 1.0

Projet : Aziz Studio Digital V2

---

# Objectif

Construire les fondations du Design System.

Aucune page ne doit être développée tant que ce sprint n'est pas terminé.

Ce sprint consiste uniquement à mettre en place les bases graphiques et techniques du projet.

---

# Règles générales

- HTML5 sémantique
- CSS moderne
- Mobile First
- Responsive
- Accessible (WCAG)
- SEO Friendly
- Code propre
- Aucun framework CSS
- Aucun framework JavaScript
- JavaScript ES6+

---

# Architecture

Respecter STRICTEMENT l'architecture existante.

Ne pas créer de nouveaux dossiers.

Ne pas modifier l'organisation actuelle.

---

# Tâche 1

Créer le fichier :

assets/css/base/variables.css

---

## Contenu attendu

Définir uniquement des variables CSS.

Le fichier doit contenir :

### Couleurs

- Primary
- Secondary
- Accent
- Background
- Surface
- Border
- Text Primary
- Text Secondary
- Success
- Warning
- Danger

Utiliser des Custom Properties CSS.

# Tâche 2

Créer :

assets/css/base/reset.css

---

Le fichier doit :

- supprimer les marges par défaut
- supprimer les paddings
- box-sizing:border-box
- images responsive
- vidéos responsive
- listes propres
- liens propres
- boutons propres

Le reset doit être moderne.

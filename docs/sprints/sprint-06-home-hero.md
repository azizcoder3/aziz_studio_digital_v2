Dépendances :

---

# Objectif

Créer une section Hero premium qui positionne immédiatement Aziz Studio Digital comme une agence web moderne spécialisée dans la création de sites internet performants pour les entreprises.

Le Hero doit inspirer confiance, démontrer l'expertise et inciter le visiteur à demander un devis.

---

# Objectif Business

Transformer les visiteurs en prospects.

Le Hero doit répondre immédiatement aux questions suivantes :

- Qui êtes-vous ?
- Que faites-vous ?
- Pour qui ?
- Pourquoi vous choisir ?
- Que dois-je faire maintenant ?

---

# Public cible

Le Hero s'adresse principalement aux :

- Hôtels
- Restaurants
- Agences immobilières
- Cliniques
- Cabinets médicaux
- Cabinets dentaires
- Pharmacies
- Salons de beauté
- Agences de voyage
- PME
- Entrepreneurs

---

# Contenu rédactionnel

## Badge

Créer un badge au-dessus du titre :

"🚀 Agence Web • SEO • Solutions Digitales"

---

## Titre principal (H1)

Créer des sites web professionnels qui développent votre activité.

---

## Sous-titre

Aziz Studio Digital accompagne les entreprises avec des sites web rapides, modernes, optimisés pour Google et pensés pour générer des contacts.

---

## Arguments clés

Afficher sous forme de liste :

- Site rapide
- Optimisé SEO
- Responsive
- Hébergement & maintenance
- Accompagnement personnalisé

---

## Boutons

Bouton principal :

Demander un devis

Bouton secondaire :

Voir nos réalisations

---

## Statistiques

Créer une zone affichant quatre indicateurs.

Utiliser des valeurs provisoires :

- 20+ projets
- 10 secteurs
- 100 % responsive
- Support disponible

Ces valeurs pourront être mises à jour ultérieurement.

---

## Illustration

Prévoir une colonne réservée à une illustration.

Utiliser un simple placeholder HTML.

Aucune image définitive.

---

# Architecture HTML

Le Hero devra être organisé en deux colonnes :

Colonne gauche :

- Badge
- H1
- Texte
- Arguments
- Boutons
- Statistiques

Colonne droite :

- Placeholder illustration

---

# Composants à utiliser

Utiliser uniquement :

- Button
- Badge
- Container
- Grid
- Section

Aucun style spécifique ne doit être recréé si un composant existe déjà.

---

# Responsive

Desktop :

Deux colonnes.

Tablet :

Deux colonnes adaptées.

Mobile :

Une seule colonne.

Les boutons doivent passer sur deux lignes si nécessaire.

---

# Accessibilité

- Hiérarchie correcte des titres
- Boutons accessibles
- Contrastes conformes
- Navigation clavier

---

# SEO

Le H1 doit contenir naturellement les expressions :

- création de sites web
- entreprise
- Congo

Le texte doit rester fluide et naturel.

---

# Performance

Aucune bibliothèque externe.

Aucune animation JavaScript.

Les animations éventuelles devront être réalisées uniquement en CSS.

---

# Critères d'acceptation

Le Sprint est terminé lorsque :

✔ Hero entièrement responsive

✔ Deux CTA visibles

✔ Arguments clairement lisibles

✔ Placeholder illustration présent

✔ Statistiques présentes

✔ Accessibilité respectée

✔ Utilisation exclusive du Design System

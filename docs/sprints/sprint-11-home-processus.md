# Les 6 étapes

Chaque carte comprend :

- Numéro
- Icône SVG
- Titre
- Description
- "Vous obtenez"
- Durée

## Étape 1

Numéro : 01

Titre : Découverte

Description :

Nous échangeons sur votre activité et vos objectifs.

Vous obtenez :

- Vision claire
- Conseils personnalisés

Durée :

1 à 2 jours

---

## Étape 2

Numéro : 02

Titre : Proposition

Description :

Nous préparons une offre adaptée.

Vous obtenez :

- Devis détaillé
- Planning

Durée :

1 jour

---

## Étape 3

Numéro : 03

Titre : Design

Description :

Conception de l'interface et validation.

Vous obtenez :

- Maquette
- Prototype

Durée :

3 à 5 jours

---

## Étape 4

Numéro : 04

Titre : Développement

Description :

Vous obtenez :

- Responsive

Durée :

1 à 3 semaines

## Étape 5

2 jours

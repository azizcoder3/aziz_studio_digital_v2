# Les Technologies / Piliers (6 cartes)

1. **HTML5 & CSS3 Modernes**
   - Icône SVG : Code / Layout
   - Description : Structure sémantique propre, animations fluides, respect des standards W3C et accessibilité web.
   - Tag / Caractéristique : Standard Web & Accessibilité

2. **JavaScript (ES6+)**
   - Icône SVG : Script / Dynamisme
   - Description : Interactivité réactive, composants légers et performances optimales sans lourdeur inutile.
   - Tag / Caractéristique : Performance & Interactivité

3. **WordPress Sur Mesure**
   - Icône SVG : CMS / Gestionnaire
   - Description : Administration intuitive, personnalisation totale et autonomie garantie pour gérer votre contenu.
   - Tag / Caractéristique : CMS & Autonomie

4. **SEO & Web Analytics**
   - Icône SVG : Search / Ranking
   - Description : Optimisation technique on-page, structures microdonnées et suivi des performances Google.
   - Tag / Caractéristique : Référencement Google

5. **Performance & Vitesse Core Web Vitals**
   - Icône SVG : Lightning / Speed
   - Description : Temps de chargement ultra-rapides, compression des médias et scores élevés sur PageSpeed.
   - Tag / Caractéristique : Chargement Ultra-Rapide

6. **Hébergement & Sécurité SSL**
   - Icône SVG : Shield / Lock
   - Description : Certificats HTTPS/SSL, sauvegardes automatiques, protection contre les menaces et haute disponibilité.
   - Tag / Caractéristique : Sécurité & Disponibilité
